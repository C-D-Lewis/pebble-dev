# Instruments

Watchface showing concise time, date, and a choice of four configurable
complication slots. The focus is on readability and usefulness. 

Features include:

- 24H time dial
- Current weather conditions
- Clear date display
- Choice of color theme for time dial
- Four complication slots capable of displaying any available complication.

Available complications:

- Watch battery level
- Phone battery level (if available)
- Step count
- Next 6 hours weather conditions
- Next 6 hours rain chance
- Current temperature on the daily low/high range
- None (empty slot)

Customization options:

- Time dial color theme
- Step goal (5000 / 7500 / 10000)
- Temperature unit (C / F)

Weather data from [OpenMeteo](https://open-meteo.com/).
